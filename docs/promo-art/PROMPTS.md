# Promo artwork: prompts to generate

40 images for the promo build's demo content and the site screenshots. Every title is invented: no real films, people, brands or logos.

## How to use this file

1. Copy a prompt block into Codex as it is. Each one already includes the shared style.
2. Generate at the size shown next to the file name.
3. Save as PNG with exactly that file name into `promo-art-src/` at the repository root (git-ignored).
4. On posters, check the title is spelt right; regenerate if not.
5. Tick the box. When all are done, tell Claude: it converts them to WebP, wires them into the promo app and redoes the screenshots and the social card.

Sizes: posters 1024x1536 (2:3), backdrops and stills 1536x1024 (3:2, cropped to 16:9 later), avatars 1024x1024.
