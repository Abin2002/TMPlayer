# Promo artwork prompts

Artwork for the promo build's demo content and the site screenshots. Every title is invented; no real
films, actors, brands or logos. 40 images in all.

## How to make and hand over the images

- Generate each image with the prompt below, at the size given: posters 1024x1536 (2:3), backdrops and
  stills 1536x1024 (3:2, cropped to 16:9 later), avatars 1024x1024.
- Save each as PNG under `promo-art-src/` in the repository root with the exact file name given
  (for example `promo-art-src/promo_quiet_orbit_poster.png`). That folder is not committed; Claude
  converts the files into the promo flavor's WebP assets.
- Check the title lettering on every poster: regenerate if a word is misspelt.

## Shared style (add to every prompt)

> Original cinematic artwork, rich colour grading, soft film grain, high detail, professional key art.
> No real people or celebrity likeness, no brand names, no logos, no watermarks, no extra text beyond
> what is asked.

Posters add: *title lettered in an elegant typeface integrated into the artwork, near the top, no
credits block, no tagline.* Backdrops and stills add: *no text at all, wide composition with calm space
on the left for overlaid text.*
